# Game Design

最終更新：2026-10-29

## 1. タイトル

**F-Sports #01「GUILD MARKET」— 王国一のギルドを見抜け**

> 予測商会として、4つのギルドの未来を読み合う。王国の商会100と同じ市場で売買し、締切のたびに全員の結果が一斉に公開される。

## 2. ゲームの中心

```text
情報を読む
→ 根拠を話し合う
→ ほかの商会の動きを予想する
→ 売買を予約する
→ 締切で一斉に約定し、新しい価格が公開される
→ 判断を修正する
→ 結果と過程を振り返る
```

プレイヤーは王国の経営者ではなく、一貫して「予測商会」です。王国経営、建設、探索、戦闘は加えません。

## 3. 人工市場と一斉注文

GUILD MARKETの市場は人工市場です（D-024）。

- 王国の市場には、プレイヤーのほかに約100のNPC商会（王国の商会100）が参加します。NPCには、流行追い、ニュース反応、逆張り、短期、長期の5つの性格があります。
- 各ラウンドは「ニュース → 注文受付 → 締切 → 一斉公開」で進みます。
- 注文受付中に出した注文は予約です。価格はまだ動かず、他の商会の予約は見えません。
- 締切で、プレイヤーとNPCの注文がまとめて市場に入り、新しい価格が決まります。全員がその新しい価格で約定します。同じギルドなら、買いも売りも同じ値段です。
- そのため、みんなと同じ向きに注文するほど不利な価格で約定し、逆を読めば有利になります。「ニュースを読む」に加えて「ほかの商会がどう動くかを読む」ことが、ゲームの中心になります。
- 市場係（王国取引所）が常に取引相手になります。参加者が1人でも、相手がいなくても売買できます。
- 山場（人気の上昇、噂による暴落、公式情報による回復）は、NPCの注文で必ず起きます（D-019）。プレイヤーの注文も価格を動かしますが、全員が逆らっても山場は消えません。

価格の計算、予約、部分約定の規則は`MARKET_SPEC.md`にあります。

## 4. 遊び方の形式

同じエンジンと市場で、進行と人数だけを変えます（D-002）。

| 項目 | 提案会議版 | 銀行イベント版 | 一人版 |

## 5. 世界観

王国では、年に一度「グランドクエスト」が開催されます。4つのギルドがそれぞれ大事業に挑戦し、最も大きな成果を上げたギルドが王国勲章を獲得します。

- 飛空艇ギルド：世界初の王国間飛行
- 錬金術ギルド：万能薬の完成
- ドラゴン輸送ギルド：大型輸送の実用化
- 魔法学校：100人の魔法使い育成

プレイヤーは、どのギルドが勲章を獲得するか予測し、「成功証」を売買します。第1シナリオの本文と値は`SCENARIO_01.md`にあります。

## 6. 市場ルール

4種類の成功証があります。価格は王国全体が考える「成功しそう度」で、合計は常に100G（整数）です。

例：

```text
飛空艇        28G
錬金術        34G
ドラゴン輸送  23G
魔法学校      15G
```

基本ルール：

- 注文は締切までの予約です。締切までは変更・取消でき、何も出さなければ保有のままです。
- 1ラウンドに、1ギルドあたり1つの注文（買いか売り）を出せます。1注文の上限は10口です（初期値）。
- 買いの予約では、支払いの上限として「口数×現在価格の1.5倍」の現金を確保します。余りは約定後に戻ります。
- 締切後に新しい価格が公開され、その価格で約定します。
- 新しい価格だと予約額を超える買いは、超えない口数まで減らして約定します（一部約定）。0口になれば不成立です。
- 売却代金は次のラウンドから使えます。
- 優勝ギルドの成功証は1口100G、それ以外は0Gで精算します。
- 現金として残したゴールドは消えません。
- 空売り、借金、レバレッジは扱いません。
- 取引はギルドの実際の成功結果に影響しません（D-008）。

公開のときに見せるもの：

- 新しい価格と前回比
- 自分の結果：約定、一部約定、不成立と、その理由
- 王国の商会100の動き（例：ドラゴン 売り61・買い9・様子見30）
- 参加者全体の動き（参加者が少ないイベントでは、個人が推定されないようにまとめる）

## 7. 親子イベントの役割

### 子ども：スカウト

- 街の評判
- 商品の人気
- ギルドマスターの発言
- SNSや住民の反応
- 最終的な売買操作

### 親：アナリスト

- 開発費
- 過去の成功率
- 資金残高
- 技術的・制度的リスク
- 子どもへの助言

親子で1台を使うため、役割別の情報は隠しません（D-018）。スカウト面とアナリスト面を同じ端末に置き、同時には片方だけを表示します。分業は情報量と制限時間で促します。ニュース提示45秒、注文受付60〜180秒のなかで両方の面を読み切るには、二人で手分けする必要があります。

対立は情報の非対称ではなく解釈から作ります。第2幕では同じ画面に「試乗希望者が1万人を突破」と「製造費が当初予算の2倍」が並び、どちらを重く見るかで判断が割れます。

一人版と提案会議版では役割を分けず、両方の面を順に読めるようにします。

## 8. レベルデザイン

新しい操作を追加するのではなく、ニュースの読み方を段階的に難しくします。

| 段階 | 直面するもの | 狙い |
| --- | --- | --- |
| 練習 | 明らかな好材料 | 予約と一斉約定を理解する |
| 第1幕 | 公開情報とプレゼン | 好きと予測を分ける |
| 第2幕 | 人気と採算の情報 | 情報を持ち寄る |
| 第3幕 | 噂、群集心理、急落 | 市場価格を疑い、ほかの商会の動きを読む |
| 第4幕 | AIレポートと一次情報 | 根拠を確認して修正する |
| 決算 | 結果と市場リプレイ | 判断を言語化する |

提案会議版の5ラウンドは、この幕の構成を圧縮したものです（`SCENARIO_01.md` §3）。

### 練習

2匹のモンスターによる模擬レースを行います。「赤ドラゴンが羽を痛めた」というニュースを出し、締切後の公開で青ドラゴンの価格が上がる様子を体験します。予約、締切、一斉公開を一度ずつ経験し、練習結果は本番資産に影響させません。

### 第1幕：ギルドプレゼン

4人のギルドマスターが60秒ずつプレゼンします。最初の予測と投資を行います。本番中に講義は挟まず、実況者は市場の動きを伝えます。

### 第2幕：人気か採算か

飛空艇ギルドの例：

- スカウト面：「試乗希望者が1万人を突破。街ではグッズも完売」
- アナリスト面：「飛空艇1機あたりの製造費が当初予算の2倍」

「人気はあるが、事業として成功するか」という対立を作ります。

### 第3幕：暴落

「ドラゴン輸送で重大事故」というSNS映像を流し、注文を受け付けます。締切で王国の商会の売りが集中し、公開の瞬間に価格の急落が分かります。

暴落と同じ向きに売った商会は最安値で約定し、逆に買った商会は暴落後の価格で買えます。どちらが正しいかは、この時点では分かりません。

各チームは、ゲーム中1回だけ使える調査券を使うか判断します。使用できるのは第3幕と第4幕の注文受付中で、どちらで切るかがそのまま判断になります（D-020）。調査先の候補：

- 王国新聞
- ギルド公式資料
- 賢者オラクルのAI分析

### 第4幕：AIと一次情報

AIレポートは答えではなく分析材料です。

```text
事故の可能性：76％
根拠：SNS投稿213件、目撃情報12件
未確認：製品番号、公式事故報告
```

その後、公式資料が公開されます。

```text
映像の製品番号は競合ギルドの旧型ドラゴン車両と一致。
```

最後の注文を受け付けます。AIを信じたかではなく、根拠と未確認事項を確認したかが判断を分けます。公式資料に先にたどり着いた商会は、ほかの商会が買い戻す前に動けます。

## 9. 一人プレイ

一人版も同じエンジンと市場で動きます。参加者1商会の試合を自動で進め、王国の商会100が市場の動きを作ります。

NPCの性格の例：

- 人気ニュースへすぐ反応する商会
- 公式資料を重視する商会
- 値下がりすると買う商会
- 市場の流れについていく商会
- 最後まで予測を変えない商会

NPCの注文は、性格ごとの規則から開発時に生成し、レビューしてから固定します（D-019、D-026）。生成AIは使いません。プレイヤーには「王国のほかの商会」として存在を明示し、実在のプレイヤーに見せかけません。繰り返し遊ぶ場合は、シードを変えた複数の注文表を使い分けます。

NPC商会は一人版だけの仕組みではありません。どの形式でも価格の主な動力です（D-019）。参加者が50組でも5人でも1人でも、シナリオの山場が同じ形で起きます。

## 10. 面白さを守るルール

- 本番中に金融用語を教え込まない
- 正解・不正解のポップアップを出さない
- 講義は冒頭3分、最後10分程度に限定する（イベント版）
- 3〜5分ごとに判断機会を作る（提案会議版は約1分ごと）
- ニュース説明は1回45秒以内を目安にする
- 注文受付は35秒（提案会議版）〜180秒（イベント版）を目安にする
- 公開は全端末と会場画面で同時に行い、その瞬間を全員で共有する
- 途中順位は見せるが、他チームの保有や予約は見せない
- 最終結果は事前に固定したシナリオから決める
- 取引結果によってギルドの成功自体を変えない

## 11. 勝敗と表彰

### メイン順位

最終資産（現金＋精算額）で決定します。

### 別表彰

- 最優秀予測賞：各幕の方向予測が正確
- リスク管理賞：大きな損失を避けながら利益を出した
- 大逆転賞：途中順位から最も上昇した
- 情報ハンター賞：調査情報を有効に使った
- ベスト親子会議賞：判断理由を分かりやすく説明した

最優秀予測賞の本命と資金配分率は、各ラウンドの約定直後における現在保有分の取得原価と現金から導出します（D-021。一斉約定では「市場停止時点」を「各ラウンドの約定直後」と読み替える）。予測専用の入力は作りません。価格上昇だけで予測が変わった扱いにはしません。

MVPでは、説明や対話に関する賞を運営者が手動で選出してもよいものとします。複雑な自動採点をMVP要件にしません。

## 12. デブリーフ

最後に市場価格を時系列で再生します。

- 噂が流れた瞬間
- 締切で売りが集中した瞬間
- AIレポートの公開
- 公式資料の公開
- 最後の注文

体験を現実の言葉へ翻訳します。

| ゲーム内の体験 | 現実の概念 |
| --- | --- |
| 複数ギルドを保有 | 分散 |
| 現金を残す | 流動性・余裕資金 |
| 人気で価格が上昇 | 群集心理 |
| みんなと同じ向きの注文ほど不利な価格で約定 | 群集心理、市場への影響 |
| 噂による暴落 | 情報リスク |
| 途中で売却 | 利確・損切り |
| 予測を変更 | 仮説修正 |
| AIの根拠を確認 | AIリテラシー |

## 13. イベント後の追加シナリオ案

題材：「錬金術ギルドの万能薬」

- 有名な冒険者が効果を絶賛
- 予約が急増
- 原材料価格が高騰
- 小規模な副作用の噂
- AI分析は成功可能性が高いと評価
- 公式試験では効果が確認されるが、大量生産が難しい

イベント本編と異なり、「良い商品」と「事業としての成功」を分けて考えるシナリオにします。内容と結末は正式制作時にレビューします。

# Game Design

最終更新：2026-09-02

## 1. タイトル

**F-Sports #01「GUILD MARKET」— 王国一のギルドを見抜け**

> 親子で結成した予測商会として、4つのギルドの未来を予測する90分。

## 2. ゲームの中心

```text
情報を読む
→ 根拠を話し合う
→ 予測する
→ 売買する
→ 新情報を受け取る
→ 判断を修正する
→ 結果と過程を振り返る
```

プレイヤーは王国の経営者ではなく、一貫して「予測商会」です。王国経営、建設、探索、戦闘は加えません。

## 3. 基本仕様

| 項目 | 内容 |
| --- | --- |
| 対象 | 小学4〜6年生と保護者 |
| 人数 | 親子30〜50組 |
| 時間 | 90分 |
| 端末 | 親子で1台 |
| 初期資金 | 1,000G |
| 投資対象 | 4ギルド |
| ラウンド | 練習＋本番4ラウンド |
| 操作 | 買う・売る・保有する |
| 特殊行動 | 調査券をゲーム中1回使用（第3幕または第4幕） |
| 主順位 | 最終保有ゴールド |
| 金銭 | ゲーム内ポイントのみ |

## 4. 世界観

王国では、年に一度「グランドクエスト」が開催されます。4つのギルドがそれぞれ大事業に挑戦し、最も大きな成果を上げたギルドが王国勲章を獲得します。

- 飛空艇ギルド：世界初の王国間飛行
- 錬金術ギルド：万能薬の完成
- ドラゴン輸送ギルド：大型輸送の実用化
- 魔法学校：100人の魔法使い育成

プレイヤーは、どのギルドが勲章を獲得するか予測し、「成功証」を売買します。

## 5. 市場ルール

4種類の成功証があります。価格は「市場が考える勝利確率」を直感的に表し、合計は100G前後になります。

例：

```text
飛空艇        28G
錬金術        34G
ドラゴン輸送  23G
魔法学校      15G
```

基本ルール：

- 買われると価格が上がる
- 売られると価格が下がる
- 市場が開いている間は売却できる
- 優勝ギルドの成功証は1口100Gで精算する
- それ以外は0Gで精算する
- 現金として残したゴールドは消えない
- 空売り、借金、レバレッジは初期版では扱わない
- 取引はギルドの実際の成功結果に影響しない

価格形成方式、購入単位、価格スリッページ、保有上限は未決定です。LMSRを有力候補とし、`ARCHITECTURE.md`と`DECISIONS.md`で管理します。

## 6. 親子イベントの役割

### 子ども：スカウト

- 街の評判
- 商品の人気
- ギルドマスターの発言
- SNSや住民の反応
- 最終的な売買操作

### 親：アナリスト

- 開発費
- 過去の成功率
- 資金残高
- 技術的・制度的リスク
- 子どもへの助言

親子で1台を使うため、役割別の情報は隠しません（D-018）。スカウト面とアナリスト面を同じ端末に置き、同時には片方だけを表示します。分業は情報量と制限時間で促します。ニュース提示45秒、市場60〜180秒のなかで両方の面を読み切るには、二人で手分けする必要があります。

対立は情報の非対称ではなく解釈から作ります。第2幕では同じ画面に「試乗希望者が1万人を突破」と「製造費が当初予算の2倍」が並び、どちらを重く見るかで判断が割れます。

一人版では役割を分けず、情報を順番に公開します。

## 7. レベルデザイン

新しい操作を追加するのではなく、ニュースの読み方を段階的に難しくします。

| 段階 | 直面するもの | 狙い |
| --- | --- | --- |
| 練習 | 明らかな好材料 | 売買操作を理解する |
| 第1幕 | 公開情報とプレゼン | 好きと予測を分ける |
| 第2幕 | 親子で異なる情報 | 情報を持ち寄る |
| 第3幕 | 噂、群集心理、急落 | 市場価格を疑う |
| 第4幕 | AIレポートと一次情報 | 根拠を確認して修正する |
| 決算 | 結果と市場リプレイ | 判断を言語化する |

### 練習：5分

2匹のモンスターによる模擬レースを行います。「赤ドラゴンが羽を痛めた」というニュースを出し、青ドラゴンの価格が上がる様子を体験します。一度だけ買って売り、練習結果は本番資産に影響させません。

### 第1幕：ギルドプレゼン

4人のギルドマスターが60秒ずつプレゼンします。最初の予測と投資を行います。本番中に講義は挟まず、実況者は市場の動きを伝えます。

### 第2幕：情報のズレ

飛空艇ギルドの例：

- 子ども側：「試乗希望者が1万人を突破。街ではグッズも完売」
- 親側：「飛空艇1機あたりの製造費が当初予算の2倍」

「人気はあるが、事業として成功するか」という対立を作ります。

### 第3幕：暴落

「ドラゴン輸送で重大事故」というSNS映像を流し、市場を短時間開きます。価格が急落したところで市場を停止します。

各チームは、ゲーム中1回だけ使える調査券を使うか判断します。使用できるのは第3幕と第4幕の2箇所で、どちらで切るかがそのまま判断になります（D-020）。調査先の候補：

- 王国新聞
- ギルド公式資料
- 賢者オラクルのAI分析

### 第4幕：AIと一次情報

AIレポートは答えではなく分析材料です。

```text
事故の可能性：76％
根拠：SNS投稿213件、目撃情報12件
未確認：製品番号、公式事故報告
```

その後、公式資料が公開されます。

```text
映像の商品番号は競合ギルドの旧型ドラゴン車両と一致。
```

最終市場を開きます。AIを信じたかではなく、根拠と未確認事項を確認したかが判断を分けます。

## 8. 一人プレイ

一人プレイでも市場を成立させるため、市場システムが常に売買相手になります。加えて、シナリオに沿って取引するNPC商会を用意します。

NPCの例：

- 人気ニュースへすぐ反応する商会
- 公式資料を重視する商会
- 値下がりすると買う商会
- 市場の流れについていく商会
- 最後まで予測を変えない商会

NPCは生成AIを必要とせず、レビュー可能なルールとタイムラインで動かします。プレイヤーには「王国のほかの商会」として存在を明示し、実在プレイヤーに見せかけません。

NPC商会は一人版だけの仕組みではありません。イベント版でも価格の主な動力として動かす案があります（D-019、Proposed）。参加人数が30〜50組でも5組でも1組でも、シナリオの山場が同じ形で起きるようにするためです。

## 9. 面白さを守るルール

- 本番中に金融用語を教え込まない
- 正解・不正解のポップアップを出さない
- 講義は冒頭3分、最後10分程度に限定する
- 3〜5分ごとに判断機会を作る
- ニュース説明は1回45秒以内を目安にする
- 市場オープンは60〜180秒を目安にする
- 途中順位は見せるが、他チームの保有銘柄は見せない
- 最終結果は事前に固定したシナリオから決める
- 取引結果によってギルドの成功自体を変えない

## 10. 勝敗と表彰

### メイン順位

最終保有ゴールドで決定します。

### 別表彰

- 最優秀予測賞：各幕の方向予測が正確
- リスク管理賞：大きな損失を避けながら利益を出した
- 大逆転賞：途中順位から最も上昇した
- 情報ハンター賞：調査情報を有効に使った
- ベスト親子会議賞：判断理由を分かりやすく説明した

最優秀予測賞の方向予測は、各ラウンド終了時の保有比率から導出します（D-021、Proposed）。予測専用の入力は作りません。

MVPでは、説明や対話に関する賞を運営者が手動で選出してもよいものとします。複雑な自動採点をMVP要件にしません。

## 11. デブリーフ

最後に市場価格を時系列で再生します。

- 噂が流れた瞬間
- 売りが集中した瞬間
- AIレポートの公開
- 公式資料の公開
- 最終売買

体験を現実の言葉へ翻訳します。

| ゲーム内の体験 | 現実の概念 |
| --- | --- |
| 複数ギルドを保有 | 分散 |
| 現金を残す | 流動性・余裕資金 |
| 人気で価格が上昇 | 群集心理 |
| 噂による暴落 | 情報リスク |
| 途中で売却 | 利確・損切り |
| 予測を変更 | 仮説修正 |
| AIの根拠を確認 | AIリテラシー |

## 12. イベント後の追加シナリオ案

題材：「錬金術ギルドの万能薬」

- 有名な冒険者が効果を絶賛
- 予約が急増
- 原材料価格が高騰
- 小規模な副作用の噂
- AI分析は成功可能性が高いと評価
- 公式試験では効果が確認されるが、大量生産が難しい

イベント本編と異なり、「良い商品」と「事業としての成功」を分けて考えるシナリオにします。内容と結末は正式制作時にレビューします。

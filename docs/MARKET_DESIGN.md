# 人工の世界・経済・市場の設計（D-042）

更新：2026-11-05
状態：**Proposed**（方向は D-042 で owner が決定。この文書の既定値は lead の提案で、owner がマージで承認する）

**架空の国の経済**（景気・金利・物価・為替）と**出来事**（ニュース）が**架空の企業の業績**を動かし、AIたちの売買が**架空の株式市場**の価格を決める。実在の企業・実在の価格は使わない。これまでの記録の仕組み（`docs/EVENT_LOG.md`）・台帳（`docs/PAPER_TRADING_RULES.md` のうち、口座・売買単位・現物だけ・配当と分割・評価）・AI の実行・画面は、そのまま使う。変わるのは **「約定の価格を外から取り込む」部分を「板寄せで決める」に替えること** と、**架空の企業と情報を作ること**。

## 1. 市場

- 架空の国の架空の取引所で、架空の企業が上場している（最初に公開する版では **6社**（3業種×2社）、のちに12社以上。§5.1）。銘柄コードは `TST` で始まらない架空のもの（例：`NEO1`）。社名・業種・発行済株式数・事業の説明は架空
- 1日の流れは今と同じ（営業日、締め 8:30、寄り付き 9:00、引け後の処理）。休場日は今の祝日の一覧を使う（暦だけで、実データではない）
- **1日に1回、寄り付きで板寄せ** をする。その価格がその日の価格（始値＝終値）で、評価にも使う
- 売買単位100株、現物だけ、空売り・信用なし、手数料0円は今のまま

## 2. 注文

- 種類は **指値と成行**。注文票の各注文に、成行か、指値（価格）を書く
- 呼値（価格の刻み）：1円。値幅制限：前日の価格の **±20% と ±1円の広いほう**（それを超える約定はしない）。価格は1円より下げない（D-045）
- 1つの注文の株数は、その会社の発行済株式数まで（D-045）
- 確定の検査は今のまま（締めの前、約定日、口座の準備、1日1回、銘柄、100株単位、売る株を持っている）。加えて、指値が値幅制限の内側で、呼値に合っていること

## 3. 板寄せ（価格の決め方）

すべての参加者のその日の注文を集め、決まったコードで1つの価格を決める。

1. 候補の価格ごとに、その価格で買える量（その価格以上の買い指値＋成行の買い）と、売れる量（その価格以下の売り指値＋成行の売り）を数える
2. **約定量が最も大きい価格** を選ぶ。並んだら、買いと売りの差（余り）が小さい価格、それも並んだら前日の価格に近い価格、それも並んだら低い価格
3. 約定量が0なら、その日は価格がつかない（前日の価格で評価し、その旨を表示する。注文は失効）
4. 余った側は、**価格の優先（成行→有利な指値）、同じ価格なら注文票の確定時刻の早い順** に約定し、最後の1件は100株単位で一部約定にする
5. 買いの現金が足りないときは、今の規則（買える最大の100株単位まで減らす）を、板寄せの前に当てる（確定時刻の順に、その日の価格で見込まず、**指値（成行は値幅の上限）× 株数** で現金を確かめる）

板寄せは純関数（`src/` の決定論的なコード）で、入力（全員の注文票）と出力（価格・各注文の約定量）を記録し、誰でも作り直せる。

## 4. 参加者

| 種類 | 数 | 動き方 | 記録 |
| --- | --- | --- | --- |
| LLM の AI 投資家 | 5体から | 情報と掲示板を読み、投稿し、注文票を出す（D-041） | `agent.run`・`post.published`・注文票 |
| 規則の AI 投資家 | 3体（今の ミア・リバ・ホールデン） | 規則で注文 | 同上 |
| マーケットメイカー | 銘柄ごとに1 | 架空の「理論価格」のまわりに、買い・売りの指値を毎日出す。在庫が偏ると値をずらす | 注文票（観戦画面のランキングには出さない） |
| ばらばらに売買する参加者 | 数十（まとめて1つのAIとして記録してよい） | 小さい数量の成行・指値を、固定シードの乱数で出す | 同上 |

- マーケットメイカーとばらばらの参加者は、**値がつかない日を減らすための流動性** で、AI 投資家の成績の比較からは外す。参加者の登録（`agent.registered`）に種類（`investor`・`market_maker`・`noise`）を書き、画面の順位には `investor` だけを出す
- **最初の持ち株と現金（D-045）：** AI投資家は現金1,000万円ちょうどで、株は持たない（台帳が、違う額と最初の配分を断る）。マーケットメイカーは、その銘柄を5,000株と現金5,000万円。ばらばらの参加者は、6社それぞれ1,000株と現金3,000万円。上場の日に `shares.allotted` で配る。数字はコードの1か所の定数（`ALLOTMENT`）

### 4.1 マーケットメイカーの動き（D-045）

- **目安の価格：** 締めより前に発表済みの決算（直近4四半期）の1株あたり利益 × 業種ごとの倍率（`fairPrice`）。発表がまだなければ上場の価格。金利はまだ入れない（入れる段階で、倍率を「1 ÷（金利＋業種ごとの上乗せ）」に替える。上乗せは、切り替えの日に価格が跳ばないように決める）
- **ふだんの日：** 持ち株が目標（5,000株）より多ければ中心を下げ、少なければ上げる（上限あり）。中心から一定の幅ずつ離して、買いと売りの指値を何段かずつ出す
- **自己約定はしない：** 自分の買いが自分の売りに届く値段では出さない。自分どうしの売買は、実際には誰も売り買いしていないのに出来高を増やして見せる（仮装売買）ので、どの日も認めない
- **値幅の端の日：** 目安の価格が値幅の外にある日は、目安に向かう側だけを、値幅の端の値段に出す（上の外なら上限で売りだけ、下の外なら下限で買いだけ）。値段は、ほかの参加者の注文と当たった日に、値幅いっぱいずつ目安に近づく。端かどうかは、持ち株でずらす前の目安の価格で決め、ばらばらの参加者と同じ決め方にする。ふだんの日に、持ち株でずらした中心が目安を少し越えることはある
- **値段がつかなかった次の日：** 前の営業日に値段がつかなかった銘柄では、その日の目安の価格を、値幅の中に収まるところまで寄せる。実際のマーケットメイカーも、市場でついている値段を手がかりにするのと同じ考え方。寄せた日は、判断の記録に寄せる前と後の価格を残す

### 4.2 ばらばらに売買する参加者の動き（D-045）

- 銘柄ごとに、乱数（固定の種と約定日から決まる）で、小さい数量の成行か指値を出す
- 売りと買いの確率は、最初の持ち株と現金からのずれで片寄らせる（株が減ったら買いを多く、現金が減ったら売りを多く）。乱数で決める部分は残す
- **値幅の端の日は、マーケットメイカーの逆の側を多く出す：** 上の外なら買い、下の外なら売りを、確率0.9で選ぶ。端の日は、持ち株と現金のずれよりこちらを優先する
- 持っていない株は売らない。現金を超えて買わない

### 4.3 決算の発表と値動き（D-045）

- 架空の世界では、**20営業日で1四半期**。上場の日に上場前の四半期を発表し、そのあとは20営業日ごとに次の四半期を発表する（`company.disclosed`）
- 最初に公開する版では、値段は決算のときに大きく動き、ふだんは小さく動く。ふだんの値動きは、ニュースと国の経済を入れる段階（§5.1 の表の1〜2）で出す
- 目標（60営業日・10通りの乱数の種で確かめる）：各社が8割以上の日に値段がつく。6社すべてに値段がつく日が半分以上。値段のつかない日が続くのは3日まで
- どの参加者も、同じ締めと同じ情報の時刻の規則に従う（先読みしない）

## 5. 世界の層

上の層が下の層を動かす。すべて**固定シードの乱数のモデル**で決定論的に作り、**公表した時点でイベントとして記録**する。AI は公表済みのものだけを見る（先読みしない。今の時刻の規則と同じ）。

| 層 | 中身 | 公表（イベント） |
| --- | --- | --- |
| 国の経済（マクロ） | 景気（成長率）、物価、政策金利、為替（自国通貨と外貨1つ） | 月次・四半期の統計の発表、中央銀行の金利の決定（例：`macro.released`） |
| 出来事（ニュース） | 原材料の値上がり、規制、災害、新技術、業界の需要の変化など。起きる確率と影響の大きさを決めておく | 速報（例：`news.published`） |
| 業種 | 景気・金利・為替・原材料への感応度（例：輸出業は円安で利益が増える、銀行は金利が上がると利益が増える、不動産は金利に弱い） | なし（企業の業績に表れる） |
| 企業 | 売上・利益・1株利益・配当方針。業種の感応度＋企業ごとのばらつき＋出来事の影響 | 四半期の決算の開示（`company.disclosed`）、配当・分割の公表 |
| 市場 | 板寄せの価格（§3） | `auction.cleared` |

- マーケットメイカーの「理論価格」は、開示された業績と金利から決まった式で計算する（業績が良ければ上がり、金利が上がれば下がる）。価格が経済から離れすぎない
- 公表の時刻は現実の市場の習慣に寄せる（統計は朝 8:50 や 引け後、決算は引け後 15:30）
- 本文（ニュースの文・決算の説明）は、最初は決まった型の文。LLM で書かせるのは後で（書かせる場合も、数字は世界のモデルが決め、LLM は文章だけ）

## 6. 実在の世界と混ぜない

- 実在の企業名・実在の銘柄コード・実在の価格・実在の人物を使わない。画面・投稿の全体に「架空の市場です」と出す
- LLM の AI には「架空の市場の架空の企業」であることをプロンプトで伝え、実在の企業の情報を使った投稿は出さない（出典は市場の中の開示と掲示板だけ）

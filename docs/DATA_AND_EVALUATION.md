# Data and Evaluation

最終更新：2026-09-03
状態：Draft

## 1. 目的

データは、参加者を細かく追跡するためではなく、次の問いへ答えるために取得します。

1. イベントが盛り上がったか
2. もう一度遊びたいと思ったか
3. 実際に追加シナリオを遊んだか
4. 親子で判断理由を話したか
5. 新情報を受けて予測を修正したか
6. ゲームが安定して完了したか
7. 複数回プレイで判断行動に変化があるか

## 2. KPIの優先順位

### 第1優先：イベント成立・盛り上がり

初期目標：

- 参加チームの80％以上が3回以上売買する
- 参加者の70％以上が「盛り上がった」または同等評価をする
- 親子双方が少なくとも一度、判断理由を話す
- 市場停止や進行不能による中止がない
- 終了前の重大な離脱が少ない

「親子双方が話した」は、自己申告、会場観察、短い振り返りを組み合わせます。音声を常時録音することは初期要件にしません。

### 第2優先：継続意向と実行動

初期目標：

- 「また遊びたい」70％以上
- 追加シナリオへの登録または開始意向50％以上
- イベント後7日以内の実プレイ30％以上
- 追加シナリオの完了率を計測できる

4週間以内に2回以上再訪する指標は、複数シナリオを配信する段階で有効になります。追加シナリオが1本だけの初期検証では主要KPIにしません。

### 第3優先：教育効果の兆候

- 各ラウンドで売買または保有を通じて予測を表現した
- 新情報後に予測または保有を変更した
- 情報源の違いを認識した
- 一つの対象へ全額を投入しなかった
- 現金を残した
- AIレポートの未確認事項を確認した
- 結果後に判断理由を説明できた

単発イベントの利益や正答だけで、教育効果を断定しません。複数回の学校利用等で変化を確認する必要があります。

### 運用品質

- 接続成功率
- 再接続回数と復帰成功率
- 注文成功率
- 注文応答時間
- 重複注文拒否数
- 市場停止後注文の拒否数
- 運営による手動修正数
- 進行遅延時間
- 障害件数と重大度

## 3. 最初から記録するイベント

名称は実装時に確定します。最低限、次の概念を記録します。

### セッション

- 参加コードからのアクセス
- チーム参加完了
- 再接続
- 離脱または最終完了

### 情報

- ニュース配信時刻
- 情報表示時刻
- 役割別情報の表示
- 調査券使用
- 選択した調査先

単に画面へ表示されたことと、本人が理解したことを同一視しません。

### 予測スナップショット

- ラウンド
- 市場停止時点
- 取得原価ベースのギルド別保有配分
- 配分から導出した本命ギルド
- 現金を含む、本命への資金配分率
- 前回スナップショットから本命が変わったか

予測専用フォームは設けません（D-021）。時価評価額ではなく現在保有分の取得原価を使い、市場価格だけで予測が変わった扱いになることを防ぎます。資金配分率の分母には現金を含め、少額を1ギルドだけ保有した状態を100％と見なさないようにします。判断理由の取得は初期イベントで必須の操作にせず、デブリーフまたは任意の短い振り返りとして扱います。

### 取引

- 一意な注文ID
- イベントID、仮名チームID
- ギルド
- 売買方向
- 数量または金額
- 見積もり時価格
- 約定結果
- 約定後価格
- 成功／拒否と理由
- プレイヤー注文かNPC注文か

### 運営

- 状態遷移
- 市場開始・停止
- ニュース配信
- 手動補正・取消
- 精算
- 緊急停止

### 結果・継続

- 最終資産
- 表彰指標
- 結果画面表示
- 追加シナリオ導線表示
- 追加シナリオ開始
- 追加シナリオ完了

## 4. 推奨する判断理由の選択肢

自由記述だけでは小学生の入力負担と分析負担が大きいため、短い選択肢を中心にします。

- 人気・評判
- ギルドマスターの説明
- 費用・資金
- 過去の実績
- 公式資料
- 王国新聞
- AIレポート
- 市場価格の動き
- 親／子どもの意見
- 直感
- その他

複数選択可とし、必要なら短い任意コメントを加えます。

## 5. 派生指標

### 予測修正率

新情報の前後で、取得原価ベースの本命または資金配分率が変化したチームの割合。価格変化だけではなく、プレイヤーの売買によって保有配分が変化した場合に限ります。

### 保有集中度

総投資額に対する最大ギルド保有の割合。分散をしたかを見る材料ですが、低いほど常に良いとは判定しません。

### 現金比率

各ラウンド終了時に現金を残した割合。単独で優劣を決めません。

### 情報反応時間

情報公開から最初の売買までの時間。速さを良さと同一視せず、群集行動や熟考の分析材料にします。

### 根拠の多様性

異なる種類の情報を判断理由として選択した数。入力内容の自己申告であることを明示します。

## 6. アンケート

子どもと保護者の回答を可能な範囲で分けます。回答負担を抑え、5段階評価＋少数の自由記述を基本にします。

候補：

- ゲームは楽しかった
- 会場は盛り上がった
- 自分で考えて売買できた
- 相手の話を聞いて判断した
- 途中で考えを変えた
- 情報が本当か考えた
- AIの根拠や未確認事項を見た
- また遊びたい
- 家でも追加シナリオを遊びたい
- 分かりにくかった点
- 一番印象に残った判断

## 7. プライバシー原則

- データ最小化を優先する
- 本名を必須にせず、商会名と仮名IDを使う
- 児童のメールアドレスを初期イベントで直接取得しない案を優先する
- 学校名、住所、生年月日などをゲームログへ含めない
- 自由記述へ個人情報を書かないよう案内する
- 分析用データと連絡先が必要な場合は分離する
- イベント主催者、開発者、分析者のアクセス範囲を決める
- 保持期間、削除手順、利用目的を本番前に文書化する
- 集計レポートでは少人数の個別行動が推測されないようにする
- テストには架空データを使う

具体的な同意、保護者への説明、法務要件は主催者と開催条件が決まった後に専門家を含めて確認します。本書は法的判断を代替しません。

## 8. 分析時の注意

- 最終利益を知識や能力の直接指標にしない
- 結果シナリオの偶然性を考慮する
- 相関を因果効果として報告しない
- 自己申告と行動ログを区別する
- NPC取引と人間の取引を分ける
- イベントごとのシナリオ差を記録する
- 途中離脱者を都合よく除外しない
- 小規模イベントの数値を一般化しすぎない

## 9. 銀行向け実施レポート案

- 参加数、完了率
- 売買回数、予測変更率
- 親子の会話に関する自己申告・観察
- 噂、AI、公式資料の前後での市場変化
- 満足度、再利用意向
- 追加シナリオの開始・完了率
- 運用上の問題と改善策
- 教育効果について言えること／まだ言えないこと

個別チームの成績表ではなく、集計と体験の学びを中心にします。

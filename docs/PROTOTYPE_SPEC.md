# Proposal Prototype Specification

最終更新：2026-09-02

## 1. 目的

銀行や協力候補の担当者が、説明だけでは分かりにくいGUILD MARKETの面白さを、5〜10分で体験できる状態にします。

これは本番システムではありません。複数端末、負荷、正式市場アルゴリズムを検証するものではなく、企画理解と初期反応を得るための提案用プロトタイプです。

## 2. 制作制約

- 制作目安：1日
- ブラウザで起動
- ログイン不要
- サーバー不要
- DB不要
- 外部API不要
- パッケージや技術スタックは実装開始時に決定
- データ保存が必要な場合はブラウザ内のみ
- 1台で最初から最後まで操作可能

## 3. 体験時間

5〜10分。90分イベントを再現せず、最も魅力が伝わる部分だけを圧縮します。

## 4. デモする体験

```text
4ギルドを見る
→ 最初の予測をする
→ 子ども情報と親情報を読む
→ 成功証を買う
→ 事故の噂で価格が急落する
→ 調査先を選ぶ
→ AIレポートと公式資料を比較する
→ 売買を修正する
→ 結果と市場リプレイを見る
```

## 5. シナリオ

「ドラゴン輸送の事故映像」を中心にします。

1. 4ギルドを紹介する
2. 1,000Gで初回投資する
3. ドラゴン輸送の人気ニュースを出す
4. NPC商会の買いで価格が上昇する
5. 事故映像の速報を出す
6. NPC商会の売りで価格が急落する
7. 調査券で情報源を選ぶ
8. AI分析は事故の可能性76％と示すが、製品番号は未確認とする
9. 公式資料で競合の旧型車両だと判明する
10. 最終売買を行う
11. ドラゴン輸送の成功を発表する
12. 市場リプレイと判断の振り返りを表示する

## 6. 必須画面／状態

画面数ではなく、1つのアプリ内状態として実装しても構いません。

### A. 導入

- タイトル
- 目的の短い説明
- 「デモを始める」

### B. 市場

- 4ギルド名、画像または仮アイコン
- 現在価格
- 保有口数
- 評価額
- 現金残高
- 買う／売る
- 次へ進むデモ操作

### C. 情報

- 共通ニュース
- 子ども情報
- 保護者情報
- 情報種別が混同されない表示

### D. 調査

- 残り1回であること
- 王国新聞
- ギルド公式資料
- 賢者オラクルのAI分析
- 選択後の調査結果

### E. 結果／リプレイ

- 成功ギルド
- 最終資産
- 価格推移
- 重要ニュースの発生地点
- 最初の予測と最後の予測
- 「何を根拠に判断したか」という問い
- 最初からやり直す

## 7. 市場の簡易挙動

正式なLMSR実装は必須ではありません。デモでは次を満たせばよいものとします。

- プレイヤーが買うと対象価格が少し上がる
- プレイヤーが売ると対象価格が少し下がる
- ニュース公開時にNPC商会の取引で価格が動く
- 価格変化が不自然な負値や100G超過にならない
- 4価格の合計が100G前後に保たれる
- 同じ手順なら概ね同じ体験を再現できる

NPCは生成AIではなく、シナリオに記述した固定ルールで動かします。

## 8. コンテンツの分離

可能な範囲で、次をコードから分離します。

- ギルド名と説明
- 開始価格
- ニュース本文
- 子ども／保護者情報
- NPCによる価格変化
- 調査結果
- 最終結果

プロトタイプで採用するデータ形式は、本番の確定仕様ではありません。

## 9. 必須ではないもの

- 複数参加者
- 運営者ログイン
- 会場スクリーンの別URL
- WebSocket等のリアルタイム同期
- クラウドDB
- 正式な認証
- 本番向け監査ログ
- 正式なLMSR
- レスポンシブ対応の完全仕上げ
- 本番用イラスト
- AI API
- ゲスっち連携
- 印刷カード生成

## 10. 受け入れ条件

- 初見の担当者が説明を受けながら10分以内に完走できる
- 少なくとも2回、売買を行える
- 噂による下落と公式情報による反転が視覚的に分かる
- 調査券を1回だけ使える
- AIレポートに根拠と未確認事項が表示される
- プレイヤーが最終判断を修正できる
- 最終資産と価格リプレイが表示される
- 再読み込みまたはリセットでデモをやり直せる
- 実データ、秘密情報、外部サービスを必要としない

## 11. プロトタイプで聞く質問

体験後、担当者またはテスト参加者に確認します。

- 何をするゲームか、短く説明できますか
- 一番面白かった瞬間はどこですか
- 分かりにくかった操作や言葉はありますか
- 親子イベントとして盛り上がるイメージがありますか
- 金融教育として扱いたいテーマはありますか
- 90分版を試してみたいと思いますか

## 12. 次フェーズへ持ち越すもの

- 正式な市場アルゴリズム
- 1注文あたりの単位と上限
- 正式なギルド名、文言、イラスト
- 銀行ブランドの扱い
- 本番の司会台本と時間配分
